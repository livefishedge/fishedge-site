# FishEdge Marketing Site

Static marketing site for [fishedge.live](https://fishedge.live). Hosted on Cloudflare Pages.

## Structure

- `index.html` — landing page
- `style.css` — design tokens + layout
- `hero.svg` — stylized map illustration (replace with a real screenshot when ready)
- `tournaments.js` — dynamic tournament calendar (edit `TOURNAMENTS` array to add/remove events)

## Deploys

Auto-deploys on push to `main` via Cloudflare Pages integration.

## Editing the tournament calendar

Edit the `TOURNAMENTS` array in `tournaments.js`. Past tournaments auto-hide based on end date.
